----------------------------------------
صلاحيات المندوب / المشرف
----------------------------------------
✓ مبيعات — تسجيل بيع (صنف · كمية · سعر) → مسودة للإدارة
  + إرسال فاتورة واتساب للعميل مباشرة
  + بيع بالباركود + طلب تحميل سيارة
✓ تحصيل — تسجيل أي مبلغ محصّل
✓ مصروفات — غاز أو أي مصروف شغل
✓ زيارة — تسجيل زيارة مع الموقع تلقائي
✓ مخزن وعملاء — عرض الأرصدة فقط (بدون تعديل)
✓ سيارة — طلب تحميل من مخزن الشركة + رصيد السيارة
✓ ملخص يومي — طباعة / حفظ PDF / مشاركة

ملحوظة مهمة:
أي عملية تُرسل لا تدخل الحسابات إلا بعد اعتماد الإدارة.
عند ضعف النت يُحفظ الشغل محلياً ويُزامَن عند عودة الشبكة.
لو مشكلة في الدخول: أرسل على الجروب.

----------------------------------------
خطوات تفعيل الحسابات مرة واحدة (الإدارة)
----------------------------------------
1) Supabase → Authentication → Providers → Email
   - فعّل Email
   - عطّل "Confirm email" للتجربة السريعة
2) Authentication → Users → Add user (لكل بريد أعلاه)
   كلمة المرور: abuyounes2026
3) من admin-reps.html سجّل دخول الإدارة ثم «مندوب جديد»
   أو نفّذ seed_reps_users.sql بعد وضع الـ UUID
4) لكل مندوب: الاسم + البريد + الشركات الأربع + المسمى (مشرف/مندوب)
5) نفّذ schema_reps.sql المحدّث (يشمل جداول السيارة)

----------------------------------------
اعتماد العمليات (الإدارة)
----------------------------------------
admin-reps.html → اختر الشركة →
  مبيعات / تحصيل / مصروفات / تحميل سيارة بانتظار الاعتماد

# نظام المندوبين v2 — GitHub + Vercel

## أسماء الملفات (إنجليزية — موصى بها لـ Vercel)
- rep.html              تطبيق المندوب (جوال)
- admin-reps.html       لوحة إدارة المندوبين
- schema_reps.sql       جداول Supabase
- config.js             مفاتيح Supabase

## الروابط بعد النشر
- https://your-app.vercel.app/rep.html
- https://your-app.vercel.app/admin-reps.html

## التثبيت مرة واحدة
1) Supabase → SQL Editor → نفّذ schema_reps.sql
2) Auth → Providers → Email → يُفضّل تعطيل "Confirm email" للتجربة
3) Auth → Settings → Enable sign-ups (لإنشاء مندوب من اللوحة)

## إنشاء مندوب
من admin-reps.html → «مندوب جديد»:
- الاسم · البريد (يوزر الدخول) · كلمة المرور · الشركات التابعة
أو يدويًا:
1) Authentication → Add user
2) SQL:
```sql
insert into rep_profiles (user_id, name, username, companies, phone, active)
values ('UID', 'اسم المندوب', 'rep@email.com', array['الراعي','الحموي'], '01xxxx', true);
```

## الإشعارات
- عند إرسال مسودة: تُسجَّل في لوحة الإدارة كـ pending فورًا
- عند تعديل/اعتماد/رفض الإدارة: يصل إشعار داخل تطبيق المندوب (جرس 🔔)

## تعديل المسودات
من الإدارة: زر «تعديل» على أي مسودة → حفظ (+ إشعار) أو حفظ واعتماد

## ملاحظات Vercel + GitHub
- ارفع الملفات بأسماء إنجليزية فقط
- config.js يحتوي المفاتيح (anon) — مناسب للواجهة الأمامية مع RLS
- بعد git push يتم النشر تلقائيًا على Vercel


## ميزات v2.1
- **أوفلاين / أونلاين**: المندوب يحفظ بيع/تحصيل/زيارة محليًا عند انقطاع الشبكة، وتُزامَن تلقائيًا عند العودة (أو زر «مزامنة الآن»)
- **تقرير أداء المندوب**: من لوحة الإدارة — مبيعات معتمدة · تحصيل · زيارات · معلّق حسب الفترة
- **حماية المخزن**: لا يُعتمد بيع إن كان الرصيد المتاح أقل من الكمية (مع خيار اعتماد الباقي فقط)


## قاعدة مهمة
جميع عمليات المندوب (بيع · تحصيل · مصروف · زيارة) تبقى **مسودات** في جداول `rep_*_draft`.
لا تُضاف إلى `company_data` (المبيعات/التحصيلات/المصروفات) إلا بعد **اعتماد الإدارة** من `admin-reps.html`.

## ميزات v2.2 (تحديث)
- **طلب تحميل سيارة**: المندوب يطلب تحميل بضاعة من مخزن الشركة → مسودة → اعتماد الإدارة يخصم من المخزن ويضيف لرصيد السيارة
- **رصيد السيارة**: ظاهر للمندوب في تبويب «سيارة» وللإدارة في لوحة الاعتماد
- **باركود متعدد**: يمكن إدخال أكثر من باركود للصنف (مفصول بفاصلة) ويُستخدم في البيع والاستعلام
- بعد رفع schema_reps.sql الجديد على Supabase تُفعَّل جداول `rep_vehicle_load_draft` و `rep_vehicle_stock`

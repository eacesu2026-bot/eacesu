------------------------------------------------------------
الخطوة 1 — إنشاء الجداول (SQL Editor)
------------------------------------------------------------
1. ادخل https://supabase.com وافتح المشروع
2. من القائمة اليسرى: SQL Editor → New query
3. افتح ملف schema.sql من النظام → انسخ كله → الصق → Run
   (ينشئ جدول company_data لبيانات الشركات)
4. استعلام جديد New query
5. افتح ملف schema_reps.sql → انسخ كله → الصق → Run
   (ينشئ: المندوبين، المسودات، الزيارات، الإشعارات، تحميل السيارة، job_title)
6. إذا ظهر Success أو لا أخطاء → الجداول جاهزة


------------------------------------------------------------
الخطوة 2 — تفعيل تسجيل البريد (Authentication)
------------------------------------------------------------
1. Authentication → Providers → Email
2. تأكد أن Email مفعّل (Enabled)
3. عطّل "Confirm email"  ← مهم جداً للتجربة
   (وإلا لن يدخل المندوب حتى يؤكد بريداً غير حقيقي)
4. احفظ Save


------------------------------------------------------------
الخطوة 3 — إنشاء 4 مستخدمين في Auth
------------------------------------------------------------
Authentication → Users → Add user → Create new user

لكل صف أنشئ مستخدماً:

  البريد: rep1@abuyounes.com   | كلمة المرور: abuyounes2026  | Auto Confirm: نعم
  البريد: rep2@abuyounes.com   | كلمة المرور: abuyounes2026  | Auto Confirm: نعم
  البريد: rep3@abuyounes.com   | كلمة المرور: abuyounes2026  | Auto Confirm: نعم
  البريد: rep4@abuyounes.com   | كلمة المرور: abuyounes2026  | Auto Confirm: نعم

بعدها يجب أن ترى 4 مستخدمين في قائمة Users.


------------------------------------------------------------
الخطوة 4 — ربط الملفات (rep_profiles) بالبريد
------------------------------------------------------------
الطريقة الأسهل (موصى بها):

1. SQL Editor → New query
2. افتح ملف seed_reps_users.sql → انسخ كله → الصق → Run
3. في النتائج يجب أن تظهر 4 صفوف: فهد، مصطفى، محمد، علي

هذه الخطوة تربط كل بريد بملف مندوب + كل الشركات + المسمى (مشرف/مندوب).


------------------------------------------------------------
الخطوة 5 — مستخدم الإدارة (لحسابات الشركات)
------------------------------------------------------------
أنشئ مستخدماً إضافياً للإدارة إن لم يكن موجوداً، مثلاً:

  admin@abuyounes.com  /  abuyounes2026

منه تدخل:
  - login.html → admin-home.html (الشركات والملخص)
  - admin-reps.html (اعتماد مسودات المندوبين)


------------------------------------------------------------
الخطوة 6 — تجربة الدخول
------------------------------------------------------------
من الموبايل أو المتصفح:

1. افتح rep.html
2. سجّل دخول بـ rep1@abuyounes.com / abuyounes2026
3. المتوقع: يظهر «مشرف فهد» وقائمة الشركات الأربع
4. كرّر مع مصطفى ومحمد وعلي

من الكمبيوتر:

1. افتح admin-reps.html
2. دخول ببريد الإدارة
3. يجب أن ترى المندوبين الأربعة في «مندوبو النظام»


------------------------------------------------------------
حل المشاكل الشائعة
------------------------------------------------------------

■ «لا يوجد ملف مندوب أو الحساب غير مفعّل»
  → المستخدم موجود في Auth لكن بدون صف في rep_profiles
  → أعد تنفيذ seed_reps_users.sql
  → أو من admin-reps: تأكد أن البريد يظهر في القائمة

■ «Invalid login credentials»
  → تأكد من البريد وكلمة المرور حرفياً
  → تأكد أن Confirm email معطّل وأن المستخدم Auto Confirm

■ «لم تُربط شركات بهذا المندوب»
  → عمود companies فارغ — نفّذ seed_reps_users.sql مرة أخرى

■ فشل إنشاء مندوب من لوحة الإدارة (signUp)
  → Authentication → Providers → Email → Enable sign-ups
  → أو أنشئ من Auth يدوياً ثم seed_reps_users.sql

■ جداول السيارة غير موجودة
  → أعد تنفيذ نهاية schema_reps.sql (جداول vehicle)
